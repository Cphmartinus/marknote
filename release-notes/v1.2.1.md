## MarkNote 1.2.1 – bug fix

- **Fixed: MarkNote could hang on the loading screen after installation.** If a second copy of MarkNote was started while another one was running or still loading (for example right after the installer had started it), the loading screen could stay on screen until Windows was restarted. A second copy now closes straight away and brings the existing window to the front.
- **Safety net:** the window is always shown within 15 seconds, and if it cannot load, MarkNote shows an error message instead of a loading screen that never closes.
- **Start-up log:** MarkNote writes a small local log (`startup.log` in `%APPDATA%\MarkNote`) to help troubleshoot start-up problems. It never leaves your computer.

### Downloads

- `MarkNote-Setup-1.2.1.exe`: installer. **Recommended.** Install it over your current version; your settings are kept.
- `MarkNote-1.2.1-portable.exe`: runs without installation.
- `MarkNote-user-guide.docx` and `MarkNote-vejledning.docx`: user guides in English and Danish.

The files are not code-signed yet, so Windows SmartScreen may show a warning the first time. Choose **More info → Run anyway**.

**If the loading screen hangs before you update:** open Task Manager (`Ctrl+Shift+Esc`), end all *MarkNote* tasks, and run the installer.
