## MarkNote 1.2.4 – right-click menu fixes and paste options

- **Fixed: the text style list in the right-click menu could not be opened.** It is now a Word-style list that shows Body text and Heading 1–4 in their own style, with a tick at the current one. It works both in the formatted page and in the Markdown pane.
- **Fixed: the two paste buttons gave the same result.** Paste now works as in Word:
  - **Keep Source Formatting (Ctrl+V)** keeps headings, bold, italic, strikethrough, links, lists and tables from Word, Google Docs and web pages. Colours, fonts and hidden Word code are removed.
  - **Keep Text Only (Ctrl+Shift+V)** pastes plain text.
  - In the Markdown pane, Keep Source Formatting converts the formatting to Markdown (`##`, `**bold**`, `- item` …), and Ctrl+V pastes text only.
  - The buttons are greyed out when there is nothing on the clipboard to paste.
- **New: Support the project** on the Help tab, after Project page. It opens Ko-fi if you would like to buy the developer a coffee. MarkNote stays free.
- The diagram editor's section heading now reads "Steps".
- The user guides describe the new paste options.

### Downloads

- `MarkNote-Setup-1.2.4.exe`: installer. **Recommended.** Install it over your current version; your settings are kept.
- `MarkNote-1.2.4-portable.exe`: runs without installation.
- `MarkNote-user-guide.docx` and `MarkNote-vejledning.docx`: user guides in English and Danish.

The files are not code-signed yet, so Windows SmartScreen may show a warning the first time. Choose **More info → Run anyway**.

If you have MarkNote 1.1.0 or later installed, you can also get this update with *Help → Check for updates*.
