## What's new in 1.0.1

- **One Word-style title bar.** The separate Windows title bar is gone. The minimize, maximize and close buttons now sit in MarkNote's blue bar, next to the quick access buttons and the document name.
- **Splash screen.** A loading screen is shown while MarkNote starts, so you can see that something is happening.
- **New icon** with an "M" for MarkNote.
- **Fixed:** In live preview, the formatted document now starts at the same height as the Markdown editor.

### Downloads

- `MarkNote-Setup-1.0.1.exe`: installer. Starts fastest and lets you open `.md` files with a double-click. **Recommended.**
- `MarkNote-1.0.1-portable.exe`: runs without installation. Unpacks itself on every start, so it starts more slowly.

The files are not code-signed yet, so Windows SmartScreen may show a warning the first time. Choose **More info → Run anyway**.

If you still see an old window after updating, an older MarkNote may be running in the background. Close it (Task Manager → end MarkNote) and start again.
