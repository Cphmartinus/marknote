## MarkNote 1.2.3 – faster start-up

- **Fixed: start-up sometimes took about 15 seconds.** On some Windows starts, the main window waited for a signal that does not always arrive while the window is hidden behind the loading screen, so it was only shown by the 15-second safety net. MarkNote now shows the window as soon as its content has loaded, which normally takes 1–2 seconds.

### Downloads

- `MarkNote-Setup-1.2.3.exe`: installer. **Recommended.** Install it over your current version; your settings are kept.
- `MarkNote-1.2.3-portable.exe`: runs without installation.
- `MarkNote-user-guide.docx` and `MarkNote-vejledning.docx`: user guides in English and Danish.

The files are not code-signed yet, so Windows SmartScreen may show a warning the first time. Choose **More info → Run anyway**.

If you have MarkNote 1.1.0 or later installed, you can also get this update with *Help → Check for updates*.
