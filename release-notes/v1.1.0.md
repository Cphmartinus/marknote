## What's new in 1.1.0

- **Mermaid diagrams.** Insert flowcharts, sequence diagrams, Gantt charts, pie charts and more from the *Insert* tab. Diagrams are written as text, drawn automatically in an Office-style look, and included when you export to PDF, Word (DOCX) and HTML. Double-click a diagram in the formatted document to edit it. Labels on arrows are shown in a small box on the line.
- **Check for updates.** MarkNote checks GitHub for new versions at most once a day and shows a bar when one is available. You can also check manually on the *Help* tab, or turn the automatic check off. The installer edition can download, verify and install the update for you. No documents or personal data are sent.
- **Redesigned Help tab** with Help, Shortcuts, About, Report a problem, Project page, language and updates.
- **User guides** in English and Danish (Word format) are available in the repository.

### Downloads

- `MarkNote-Setup-1.1.0.exe`: installer. Starts fastest, opens `.md` files with a double-click, and can install future updates for you. **Recommended.**
- `MarkNote-1.1.0-portable.exe`: runs without installation. Unpacks itself on every start, so it starts more slowly.

The files are not code-signed yet, so Windows SmartScreen may show a warning the first time. Choose **More info → Run anyway**.

If you still see an old window after updating, an older MarkNote may be running in the background. Close it (Task Manager → end MarkNote) and start again.
