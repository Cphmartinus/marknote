## MarkNote 1.0.0 – first release

A Word-style Markdown reader and editor for Windows.

- Ribbon interface with Home, Insert, View, Export & Tools and Help tabs
- Three views: raw Markdown, live preview and reading mode, with WYSIWYG editing in the formatted document
- Document tabs
- Open `.docx` and `.html` files, converted to Markdown automatically
- Export to PDF, DOCX, HTML and plain `.md`
- Tables, images, links, footnotes, comments and LaTeX formulas
- Version history with automatic snapshots, find and replace with regex
- Light, dark, sepia and Word Blue themes
- 13 languages, following the Windows language by default

The files are not code-signed yet, so Windows SmartScreen may show a warning the first time. Choose **More info → Run anyway**.
