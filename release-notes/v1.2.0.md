## What's new in 1.2.0

- **Diagrams without code.** A new visual diagram editor lets you create flowcharts, sequence diagrams, pie charts and Gantt charts by filling in simple tables, with a live preview next to them. Choose shapes, colours, arrow types and labels from drop-down lists, and add steps with one click. You do not need to know Mermaid, but the generated code is still available on the *Code* tab.
- **Edit existing diagrams** by double-clicking them in the formatted document, or by placing the cursor in the diagram code and clicking *Insert → Diagram*. Diagrams that use features the editor does not support open on the *Code* tab, so nothing is lost.
- **User guides** in English and Danish (Word format) are now attached to the release.

### Downloads

- `MarkNote-Setup-1.2.0.exe`: installer. Starts fastest, opens `.md` files with a double-click, and can install future updates for you. **Recommended.** You can install it over an earlier version; your settings are kept.
- `MarkNote-1.2.0-portable.exe`: runs without installation. Unpacks itself on every start, so it starts more slowly.
- `MarkNote-user-guide.docx` and `MarkNote-vejledning.docx`: user guides in English and Danish.

The files are not code-signed yet, so Windows SmartScreen may show a warning the first time. Choose **More info → Run anyway**.

If you have MarkNote 1.1.0 installed, it will tell you about this update the next time it checks (at most once a day), or choose *Help → Check for updates*.
