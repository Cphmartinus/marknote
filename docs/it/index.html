Editor Markdown gratuito per Windows · Open source Markdown, impaginato come un documento Word.

Un editor e visualizzatore Markdown con la barra multifunzione, il menu contestuale e la barra del titolo blu che conosci già da Word, e sotto semplici file .md. Crea diagrammi senza codice, trasforma documenti Word in Markdown ed esporta in PDF e DOCX.

Windows 10 & 11 · Licenza MIT · Nessun account · Nessuna telemetria

02 — Come funziona

Dal testo semplice a una pagina finita.

Quattro momenti in cui Markdown sembra un programma di videoscrittura.

01 / SCRIVI

Scrivi Markdown, vedi il documento.

Markdown a sinistra, la pagina formattata a destra. Scrivi in uno dei due riquadri e l’altro segue, così lavori come preferisci.

02 / DIAGRAMMA

Diagrammi senza una riga di codice.

Aggiungi passaggi, scegli forme e colori, collegali ed etichetta le frecce. Diagrammi di flusso, di sequenza, a torta e di Gantt si disegnano mentre scrivi.

03 / FORMATTA

Clic destro, proprio come in Word.

Una mini barra degli strumenti per titoli, grassetto, evidenziazione ed elenchi, opzioni di incollamento, un menu Inserisci e Nuovo commento, proprio dove si trova già il mouse.

04 / CONDIVIDI

Rileggilo e invialo come Word o PDF.

La modalità lettura mostra il documento come una pagina. Esporta in un vero DOCX, in PDF o in una pagina web autonoma, con diagrammi e formule inclusi.

07 — Domande

Domande su MarkNote, con risposta.

MarkNote è gratuito?

Sì. MarkNote è gratuito e open source con licenza MIT. Non ci sono account, abbonamenti, pubblicità né versioni a pagamento.

Come apro un file .md in Windows?

Installa MarkNote con MarkNote-Setup.exe. Da quel momento i file Markdown si aprono in MarkNote con un doppio clic. Puoi anche usare File → Apri o trascinare un file nella finestra.

Posso convertire un documento Word in Markdown?

Sì. Apri un file .docx o .html in MarkNote e viene convertito in Markdown, immagini comprese. Puoi anche fare il contrario ed esportare il Markdown in un vero documento Word o in PDF.

Devo conoscere la sintassi Markdown?

No. Puoi formattare con la barra multifunzione e il menu contestuale, scrivere direttamente nella pagina formattata e creare diagrammi in un editor visuale. MarkNote scrive il Markdown al posto tuo, e le descrizioni comandi mostrano la sintassi se vuoi impararla.

MarkNote supporta i diagrammi Mermaid?

Sì. Diagrammi di flusso, di sequenza, a torta e di Gantt si creano nell’editor dei diagrammi senza scrivere codice e vengono salvati come Mermaid nel file. Gli altri tipi di diagrammi Mermaid si possono scrivere come codice.

Perché Windows mostra un avviso di SmartScreen?

MarkNote non ha ancora la firma del codice, quindi Windows non riconosce l’autore. Scegli Ulteriori informazioni → Esegui comunque. Il codice sorgente è pubblico e ogni versione viene compilata da GitHub Actions a partire da quel codice.

MarkNote funziona offline?

Sì. Tutto gira sul tuo computer. L’unica richiesta di rete è un controllo facoltativo delle nuove versioni su GitHub, al massimo una volta al giorno, e puoi disattivarlo.

Esiste una versione per Mac o Linux?

Per ora no. MarkNote è fatto per Windows 10 e Windows 11.

Come posso sostenere lo sviluppatore?

MarkNote è gratuito e lo resterà. Se ti fa risparmiare tempo, puoi offrire un caffè allo sviluppatore su Ko-fi. Aiuta anche segnalare bug, proporre funzioni e parlare di MarkNote ad altri.
